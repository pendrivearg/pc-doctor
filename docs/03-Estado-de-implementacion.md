# PC DOCTOR AI — Estado de implementación

**Actualizado:** 1 de noviembre de 2026 · **Versión:** 0.2.0 (prototipo funcional, Fases 2–4 iniciadas)

## Decisiones tomadas

- **El pendrive se vende (precio bajo).** No se usa ningún dato o componente con licencia no comercial (por ejemplo PCGamingWiki, CC BY-NC-SA).
- **Costo cero (inamovible):** nada de certificados, hosting ni servicios pagos.
- **Código abierto, GPL-3.0** (`LICENSE`, `THIRD-PARTY-NOTICES.md`). Permite la firma digital gratuita para código abierto y publicar actualizaciones gratis en GitHub Releases. Se vende el pendrive armado, probado y actualizado; el código es libre.
- **Permisos:** el diagnóstico no pide permiso; las reparaciones, como máximo un aviso de Windows por sesión (a implementar con el agente elevado).
- **Interfaz:** Avalonia 11.3 (rama estable conocida). Avalonia 12 se evaluará cuando la base esté estable.
- **Política de reparaciones en la versión 0.x:** se habilitan acciones de madurez **T1** (lógica probada con pruebas automáticas, incluida la reversión), siempre con verificación posterior, reversión automática si falla y la etiqueta «En prueba». En la versión 1.0 el mínimo pasa a **T2** (laboratorio de VMs Windows 10 + 11).

## Qué todavía NO está (y por eso no aparece en la interfaz)

- IA generativa local (llama.cpp + modelos): construida y medida, apagada porque no mejoró el resultado (ver evaluación arriba).
- Escaneo antivirus integrado (Defender/ClamAV), cuarentena — Fase 4 (hoy se guía a Seguridad de Windows).
- Reparaciones con permiso de administrador (Windows Update, SFC/DISM, cola de impresión, controladores) — necesitan el laboratorio de VMs para pasar a T2.
- Intérprete: con 1017 fichas, las consultas dichas de forma muy distinta a las frases de las fichas aciertan menos (17/25 entre las 3 primeras). Conviene mejorar el intérprete (por ejemplo, usar también el título y la explicación de cada ficha). Nombres de menús en castellano a revisar en algunas fichas nuevas (las fuentes estaban en inglés; donde no había certeza se describe la opción).
- Requisitos de juegos, compatibilidad Windows 11 completa (lista de CPUs) — Fase 8.
- Actualizaciones: el sistema está hecho y probado; falta el repositorio público de GitHub (cuenta del dueño) para publicar la primera versión.
- Firma de código de Windows (para que no aparezca «Windows protegió su PC»): SignPath Foundation la da gratis, pero pide nombre y apellido del responsable; el dueño decidió no darlos por ahora. El repositorio ya cumple los demás requisitos (política de firma, privacidad, compilación en GitHub).
- Modo rescate: falta probar el arranque en PCs reales (varias marcas), conexión por Wi-Fi (hoy solo cable para actualizar firmas), y arranque en PCs viejas sin UEFI (BIOS antiguo).
- Firma de código: hay que solicitar la firma gratuita para código abierto una vez publicado el repositorio. Hasta entonces el programa funciona sin firma en la mayoría de las PCs.
- DISM «reparar» no tiene prueba automática (tarda hasta 40 minutos y necesita Internet): queda oculto hasta probarlo en el laboratorio de máquinas virtuales.

## Una comprobación pendiente del usuario

El botón **«Completar la revisión con permiso»** relanza la herramienta con permiso de administrador. Requiere aceptar el aviso de Windows (UAC), algo que solo puede hacer una persona: está implementado pero no se pudo probar automáticamente.

## Cómo compilar y probar

```bash
dotnet test tests/PCDoctor.Tests
dotnet run --project src/PCDoctor.Cli -- diagnosticar --tecnico
```

Publicación al pendrive: ver `packaging/` (publicación self-contained de un solo archivo de `PCDoctor.App` y `PCDoctor.Cli`, más `knowledge/` y `data/` en `X:\pcdoctor\`).
